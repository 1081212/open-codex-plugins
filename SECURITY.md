# Security Policy

Do not report vulnerabilities by opening a public issue when the report contains secrets, personal data, private document contents, or an unpatched exploit.

Use GitHub's private vulnerability reporting feature when it is enabled for this repository. If it is unavailable, open a minimal issue that contains no sensitive details and asks the maintainers for a private contact channel.

Never include real tokens, application secrets, OAuth responses, profile archives, private URLs, or user documents in a report or test fixture.
